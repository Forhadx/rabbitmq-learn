# RabbitMQ basic

    producer -> exchange -> binding key -> queue -> consumer

    - producer: make the message
    - exchange: receive message from producer and forward to queue based on binding key
            4 type exchange
                1. direct
                2. topic
                3. fanout
                4. headers
